# 🏛️ ArtHistory — VR-Музей

**ArtHistory** — это иммерсивное VR-приложение на базе **Unreal Engine 5**, которое превращает изучение мировой истории в интерактивное приключение. Исследуйте залы музея, находите утраченные артефакты в их естественной среде обитания и соберите собственную коллекцию величайших достижений человечества.

---

## ✨ Особенности проекта

* **🎨 Интерактивные экспонаты**
  Система осмотра и захвата 3D-артефактов, реализованная с помощью физических взаимодействий в VR. Каждый объект можно изучить детально.

* **🌀 Порталы времени**
  Уникальная механика бесшовных переходов. Найдите портал в музейной комнате, чтобы мгновенно переместиться в реконструированную среду: от джунглей мезозоя до исторических сражений.

* **🌍 Полное погружение**
  Использование высококачественных PBR-материалов создает эффект абсолютного присутствия.

* **⚙️ Технологии будущего**
  Проект построен на **Unreal Engine 5**, используя системы Blueprints для сложной игровой логики и оптимизированные методы рендеринга для VR-гарнитур.
